# Inhouse Request Complete v1

Rankviz internal outreach management system.

Stack:
- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Supabase
- Google OAuth ready
- Vercel ready

Modules:
- Authentication
- Dashboard
- Projects
- Requests
- Status Workflow
- Guest Post Anchor Sync
- Import System

Run:
npm install
npm run dev
